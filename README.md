# 酒器おとし

上から酒器を落として、同じ器どうしをくっつけて大きく育てる、落ちもの合体パズルです。お猪口から始まり、ぐい呑み・升・片口・徳利・ちろり・四合瓶・一升瓶・角樽・斗瓶、そして菰樽まで、11段。箱からあふれたら終わりです。

遊ぶ: https://y-kanno-sakenote.github.io/sake-drop/

- 杉玉：触れた器を一段育てます
- 酔っ払い：じゃまものです。一升瓶以上の酒を飲んで消えます（飲まれた酒は一段小さくなります）
- 記録は遊んでいる端末の中にだけ残ります（自分のベスト5）

使っているもの
- 物理エンジン matter.js 0.19.0（MIT License）
- 題名の文字 DotGothic16（SIL Open Font License 1.1）。題名の5文字だけを埋め込んでいます
- 器・背景のドット絵は Canva で生成し、合同会社サケノテが手を加えたものです
- 効果音と音楽は、ブラウザの中でその場で合成しています
